Por que o Hub atualiza sozinho?

Hospedado como portal-fiscal no GitHub Pages.

1

Sem cópia de código

O Hub guarda apenas nome, descrição e URL em tools.json. O código-fonte continua em cada um dos … repositórios.

2

Iframe + link oficial

O botão Abrir carrega a URL ao vivo em um visualizador interno. O botão Nova aba abre o Pages original.

3

Nova ferramenta em 1 linha

Para o …º site, adicione um bloco em tools.json e publique. Nenhuma alteração de layout é necessária. Favoritos ficam salvos no navegador (localStorage).
